Privacidad

Reclama.ai se ha diseñado para minimizar el tratamiento de datos personales. La aplicación funciona de forma local en tu navegador.

Qué ocurre con lo que escribes

  • El contenido no se envía a una API, modelo de IA, base de datos ni analítica.
  • No se crea una cuenta ni se conserva historial.
  • Al recargar o empezar de nuevo, el contenido se elimina de la memoria.
  • Los PDF y TXT se generan en tu dispositivo.

Datos técnicos de alojamiento

El proveedor puede tratar datos técnicos imprescindibles para servir la web, como IP, fecha, ruta, navegador y registros de seguridad. No recibe el contenido del formulario.

Cookies y analítica

La versión actual no instala cookies propias, no usa publicidad y no incorpora analítica.

Recomendaciones

No introduzcas datos innecesarios. Evita contraseñas, tarjetas completas, claves, datos médicos o información de terceros salvo que sea imprescindible y tengas derecho a usarla.
