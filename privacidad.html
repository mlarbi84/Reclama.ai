Privacidad

Reclama.ai se ha diseñado para minimizar el tratamiento de datos personales. La aplicación funciona de forma local en tu navegador.

Qué ocurre con lo que escribes

  • El relato, las respuestas y el borrador no se envían a una API, modelo de IA, base de datos ni servicio de analítica.
  • No se crea una cuenta ni se conserva un historial.
  • Al recargar la página o empezar de nuevo, el contenido se elimina de la memoria de la aplicación.
  • Los PDF y archivos de texto se generan en tu propio dispositivo.

Datos técnicos de alojamiento

El proveedor de alojamiento puede tratar datos técnicos imprescindibles para servir la web, como dirección IP, fecha, ruta solicitada, navegador y registros de seguridad. Este tratamiento es independiente del contenido del relato y del borrador, que no se transmite al servidor.

Cookies y analítica

La versión actual no instala cookies propias, no usa publicidad y no incorpora herramientas de analítica.

Recomendaciones

No introduzcas datos que no sean necesarios. Evita incluir contraseñas, números completos de tarjeta, claves, datos médicos o información de terceros salvo que sea imprescindible y tengas derecho a usarla.

Contacto

Para informar de una incidencia de privacidad, utiliza el apartado de incidencias del repositorio público del proyecto.
